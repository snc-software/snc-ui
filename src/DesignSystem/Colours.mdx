# Colours

The full brand and semantic colour palette, sourced from `design-tokens.json`. Raspberry,
Sky, and Neutral are raw scales and stay the same in both modes. Mode tokens and semantic
status triads flip under the `.dark` class, so each of those groups shows a light and a
dark section below — Storybook's light/dark toolbar toggle doesn't affect this page,
since it only re-themes live component stories, not static MDX content like these
swatches.
