# Fonts

Two type families make up the design system: **JetBrains Mono** for headings, and
**Manrope** for body copy and UI chrome. Both load via Google Fonts and ship as SIL OFL
(free, commercial use).

## Heading — JetBrains Mono

`--snc-font-family-heading`. Monospaced and wider than a proportional face — apply tight
letter-spacing (`-0.02em` or so) at large heading sizes (H1/H2) to avoid overly loose
type.

<Typeset
  fontFamily="'JetBrains Mono', monospace"
  fontSizes={[14, 16, 20, 24, 32, 40]}
  fontWeight={600}
  sampleText="Hello World"
/>
